# Plataforma Amis

O AMIS é uma plataforma feita para o público feminino, criada com a ideia de ser um espaço de acolhimento e troca de experiências sem seguir o modelo tradicional das redes sociais.
A proposta é que as pessoas compartilhem histórias, desabafos e conteúdos úteis sem a pressão de seguidores, curtidas ou construção de uma identidade pessoal.



## Descrição

Existem dois tipos de perfil dentro da plataforma, cada um com um objetivo diferente para manter a comunidade organizada.

Perfil pessoal: criado para que cada usuária participe da comunidade. Nele é possível compartilhar desabafos, publicar experiências, interagir com conteúdos e registrar momentos pessoais dentro do AMIS, sem a necessidade de construir uma imagem pública.

Perfil de página: pensado para perfis voltados à publicação de conteúdo. Essas páginas poderão compartilhar dicas, reflexões, textos, funcionando como espaços de conteúdo para que outras usuárias acompanhem temas de seu interesse.
